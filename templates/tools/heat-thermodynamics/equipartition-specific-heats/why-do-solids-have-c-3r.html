It has 3 kinetic and 3 potential energy terms. Each holds ½kT, so an atom stores 3kT and a mole stores 3RT. So C ≈ 3R = 24.9 J/mol·K, whatever the metal. Lead only looks cheaper to warm because its atoms are heavy, so a gram contains fewer of them.{% endblock %} {% block try_items %}
