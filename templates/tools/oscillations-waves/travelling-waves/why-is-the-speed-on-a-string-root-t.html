Pull it tighter or make it heavier and watch who wins.{% endblock %} {% block why_text %}At the top of a pulse, tension pulls the string back down. A tighter string pulls harder (force ∝ T). A heavier string has more inertia (mass ∝ μ). So the string snaps back with acceleration ∝ T/μ, and the pulse speed is √(T/μ).{% endblock %} {% block notes %}
Slow motionThe animation runs 20 times slower than real life, or the pulse would cross the string too fast to see. The close-up is a sketch of the idea, not to scale. The full derivation uses a small pulse on a string stretched by T.
