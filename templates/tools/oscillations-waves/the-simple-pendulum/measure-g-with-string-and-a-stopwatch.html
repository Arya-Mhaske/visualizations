Your thumbs are slow, so why time 20 swings and not 1?{% endblock %} {% block why_text %}Starting and stopping a stopwatch always adds a small error, about the same size however long you time. Timing N swings spreads that one error over N periods, so the error in T is N times smaller. That is why the book says to time 20 swings.{% endblock %} {% block try_items %}

  • Set your error to 0. What is left in the error? Raise the swing angle and watch it grow.
