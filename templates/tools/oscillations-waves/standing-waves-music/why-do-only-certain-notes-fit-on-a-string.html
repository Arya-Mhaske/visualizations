Change the frequency and watch the waves bounce back and forth.{% endblock %} {% block why_text %}Each wave runs to the fixed end, flips, and comes back. It meets the driver again after one round trip, 2L. If 2L is a whole number of wavelengths, every return arrives in step and the swings pile up. Any other frequency lets each return arrive out of step with the last, so they cancel. That is why only νₙ = nv/2L survives.{% endblock %} {% block try_items %}
  • Press Mode 1, then Mode 2. Count the half-wavelengths in L. What do you notice?
  • Set the round trips to 0, then raise them to 10 at 200 Hz. Do the same at 260 Hz. Which one piles up?
  • Shorten L with the slider. Press Mode 1 again and listen: does the lowest note go up or down?
