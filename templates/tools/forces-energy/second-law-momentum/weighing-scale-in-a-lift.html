{% extends "tools/base_tool.html" %} {% block lead %}A person stands on a scale in a lift. The scale reads the force it pushes up with, which is not always the weight.{% endblock %} {% block why_text %}The scale force R obeys R − mg = ma. Accelerating upward, R is bigger than mg; accelerating downward, R is smaller; in free fall (a = −g) the reading is zero. The scale reads how hard it pushes, not the mass.{% endblock %} {% block try_items %}
  • Accelerate upward at 2 m/s². Is the reading above or below the weight?
  • Accelerate downward at the same rate.
  • Set a = −9.8 m/s². What does the scale read?
