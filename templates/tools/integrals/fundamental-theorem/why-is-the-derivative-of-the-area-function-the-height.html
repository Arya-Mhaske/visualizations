Add a thin strip of width h and see how fast the area grows.{% endblock %} {% block why_text %}The strip is almost a rectangle of height f(x) and width h, so ΔA ≈ f(x)h. Divide by h: ΔA/h ≈ f(x). As h shrinks, the approximation becomes exact. So A′(x) = f(x): the rate at which area grows is the height of the curve.{% endblock %} {% block try_items %}

  • Shrink h to 0.05. What happens to the difference?
  • Where f is largest, is A growing fastest?
