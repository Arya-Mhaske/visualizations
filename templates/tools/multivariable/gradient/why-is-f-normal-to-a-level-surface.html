{% extends "tools/base_tool.html" %} {% block lead %}Draw a path on a level surface and check that the gradient is at a right angle to its tangent.{% endblock %} {% block why_text %}On a level surface F is constant, so along any path in it d/dt F(r(t)) = 0. The chain rule says this equals ∇F · r′(t). So ∇F is perpendicular to every tangent direction of the surface, which is exactly what it means to be a normal.{% endblock %} {% block notes %}
Note The dot product is not exactly 0 in the readout because the tangent is found numerically.
