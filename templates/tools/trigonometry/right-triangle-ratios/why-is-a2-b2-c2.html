Slide them and see what is left empty.{% endblock %} {% block why_text %}The big square has side a + b, so its area never changes. The four triangles never change either. So the empty area is the same at the start and at the end. At the start it is one tilted square with side c, so area c². At the end it is two squares, a² and b². Therefore c² = a² + b².{% endblock %} {% block try_items %}
