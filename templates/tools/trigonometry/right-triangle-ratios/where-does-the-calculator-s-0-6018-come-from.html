How close does opposite ÷ hypotenuse get to the calculator's sin 37°?{% endblock %} {% block why_text %}The ratio depends only on the angle, so every 37° triangle gives the same number. A ruler can only read to the nearest millimetre, so each measurement is a little off. A small triangle shows that error badly. A large triangle shrinks it, because half a millimetre is a tiny part of a long side. The calculator's 0.6018 is what the ratio would be with no ruler error at all.{% endblock %} {% block try_items %}

  • Slide the hypotenuse up to 100 cm. Does the ratio get closer to 0.6018?
