At 90° the point is at (0, 1), so x = 0 and the fraction asks for 1 ÷ 0, which has no answer. Just before 90°, x is tiny and positive, so tan is huge and positive. Just after 90°, x is tiny and negative, so tan is huge and negative. The values run off to +∞ on one side and −∞ on the other, and there is no single number in between.{% endblock %} {% block try_items %}
