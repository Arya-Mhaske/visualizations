{% extends "tools/base_tool.html" %} {% block lead %}A sine wave has a highest point, so it has an amplitude. Try to find the highest point of a tangent curve.{% endblock %} {% block why_text %}Amplitude means half the distance from the lowest point to the highest. Tangent has no highest point. Raise H as high as you like, and the curve climbs past it a little closer to the asymptote. So there is no number to call an amplitude. The number A in front of tan still does something: it stretches the curve vertically, so the point at x = π/4 sits at height A.{% endblock %} {% block try_items %}
