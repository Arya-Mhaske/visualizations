Find out how far the wave moves, and why it depends on B as well.{% endblock %} {% block why_text %}With a head start C, the arrow is already at angle C when the clock reads 0. It needs Bx = −C to be at angle 0, so the cycle that "should" begin at x = 0 begins at x = −C ÷ B. A positive C moves the wave to the left. The shift is divided by B because a faster arrow (larger B) uses up the same head start in less time.{% endblock %} {% block try_items %}
