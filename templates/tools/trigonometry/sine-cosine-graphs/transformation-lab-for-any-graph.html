{% extends "tools/base_tool.html" %} {% block lead %}A, B, C and k are not special to sine. Try them on any graph and watch where the marked points go.{% endblock %} {% block why_text %}Anything done after f changes the heights: A stretches or flips them, and k lifts them. Anything done to x, inside the brackets, works backwards on the picture: B squeezes the graph sideways by dividing the distances, and C moves it by −C ÷ B. So y = A f(Bx + C) + k is one idea: the outside changes the heights, the inside changes the positions.{% endblock %} {% block try_items %}
  • Start from x² with only k = 1. Which way did the graph go, and what happened to the marked points?
  • Switch on "mirror left–right" for |x| or x². What changes? Try it on x³/3 and on sin x.
  • Set B = 2 and C = 1. Is the graph moved by 1 or by ½? Check against −C ÷ B.
