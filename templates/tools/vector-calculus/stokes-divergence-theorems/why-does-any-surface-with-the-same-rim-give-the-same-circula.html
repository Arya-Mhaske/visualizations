Push the net up into a tall dome, or lean it. The rim does not move.{% endblock %} {% block why_text %}The field F = (−y + z, x, y) has the same curl everywhere. The circulation round the rim never changes, because the rim never changes. Stokes' theorem says the curl through the net must match it. So every net with that rim catches exactly the same total curl.{% endblock %} {% block notes %}
Note This works for any net, not just domes, as long as it is a smooth surface with the rim as its edge and its normal points the right way for the direction of the rim.
