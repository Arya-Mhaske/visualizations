{% extends "tools/base_tool.html" %} {% block lead %}Bring in charges one at a time and add their forces on a test charge, tip to tail.{% endblock %} {% block why_text %}The force of one charge on another does not depend on whether a third charge is present. So each source pushes or pulls the test charge as if it were alone, and the forces simply add as vectors. This is the principle of superposition. The tip-to-tail chain gives the same answer in any order.{% endblock %} {% block try_items %}
  • Use one source only. Which way is the force for a + charge? For a − charge?
  • Add the second source. Does the first arrow change?
  • Set two sources equal and opposite in the same place relative to the test charge. Can the net force be zero?
