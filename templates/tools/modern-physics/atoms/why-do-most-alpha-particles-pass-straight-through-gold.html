{% extends "tools/base_tool.html" %} {% block stage_class %}viz-stage--square viz-stage--scroll{% endblock %} {% block lead %}Fire a row of alpha particles at a gold nucleus from different heights. The closer one passes, the more it bends.{% endblock %} {% block why_text %}The nucleus repels alphas with a force ∝ 1/r², which is strong only very close in. The nucleus is about 10⁴ times smaller than the atom, so almost every alpha passes far away and goes nearly straight. Only a head-on one bounces back. An atom is mostly empty space.{% endblock %} {% block try_items %}
