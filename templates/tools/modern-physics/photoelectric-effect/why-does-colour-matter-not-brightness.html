First turn the brightness all the way up with red light. Then switch to a weak ultraviolet beam.{% endblock %} {% block why_text %}Each photon hands all of its energy hν to one electron, or none. Red photons each carry too little energy to pay the escape cost φ₀, so a million of them free nobody. Brighter light only means more photons, so more electrons once the colour is right, never faster ones.{% endblock %} {% block try_items %}
  • Set the colour to 680 nm and the brightness to 12. Do any electrons leave? What is the total light energy compared with φ₀?
  • Move the colour down until electrons first appear. Which wavelength is that, and how does it compare with the threshold colour?
  • At 300 nm, raise the brightness from 1 to 12. What changes: the number of electrons, or the length of each arrow?
    • {% endblock %} {% block notes %}
    Note Classical wave theory said enough bright light should eventually free electrons. Experiments show it never does below the threshold colour. Einstein explained this in 1905 with light quanta.
