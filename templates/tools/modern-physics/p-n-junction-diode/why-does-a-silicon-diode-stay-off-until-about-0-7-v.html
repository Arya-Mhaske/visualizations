{% extends "tools/base_tool.html" %} {% block stage_class %}viz-stage--tall viz-stage--scroll{% endblock %} {% block lead %}Electrons on the n side have a spread of energies. Only the fastest can climb the barrier. Raise the voltage and see how few can climb at first, and how quickly that changes.{% endblock %} {% block why_text %}The share of electrons with enough energy falls off exponentially with the barrier height, e−barrier/VT. While the barrier is large, almost none can climb, so the current is tiny. Every 60 mV off the barrier multiplies the climbers by about ten, so the current soon shoots up. Near 0.7 V the barrier is gone and the current reaches milliamps. That is the "knee".{% endblock %} {% block try_items %}
  • Start at 0 V and raise V by 0.1 V at a time. How many times does the current grow at each step?
  • Switch the top graph to Log scale. What shape is the curve, and what does that say about the share?
  • At what voltage does the current first pass 1 mA? Does that match the "about 0.7 V" in the title?
    • {% endblock %} {% block notes %}
    Note The top graph is the Boltzmann factor e−E/kT at 300 K, so the height of the curve where the dashed line cuts it is the share able to climb. The current is I = Is(eV/VT − 1) with Is = 4.4 × 10−15 A, chosen so that 0.7 V gives about 2.5 mA. The "0.7 V" is where the current becomes noticeable. It is not a sharp switch, and germanium's is about 0.3 V.
