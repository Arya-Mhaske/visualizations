Raise the reverse voltage and see what finally changes.{% endblock %} {% block why_text %}In reverse bias the field sweeps across only the minority carriers: electrons in the p side and holes in the n side. With 10²² dopants per m³ there are about 10¹² times fewer of them than majority carriers, so the current is only a few μA, and it hardly grows with voltage. At the breakdown voltage the field is so strong that a crossing carrier knocks new carriers loose, and those knock out more. Each starting carrier brings a crowd, and the current shoots up.{% endblock %} {% block try_items %}

    Note The breakdown is drawn with an empirical model: each carrier crossing frees a new pair with probability (V/Vbr)4, so the average number of carriers per starting carrier is M = 1/(1 − (V/Vbr)4). The six rows use the same random draws at every voltage, so they only get longer as V rises. At Vbr the diode holds its voltage and the circuit sets the current. The slight rise before breakdown is the layer getting wider and generating a few more pairs. Heavily doped diodes break down by a different effect (the Zener effect), which comes later in the chapter.
