{% extends "tools/base_tool.html" %} {% block lead %}Walk a circle round a long straight wire and add up the field along each step. The total always comes out as μ₀ times the current inside.{% endblock %} {% block why_text %}By symmetry the field is the same size all round a circle, and it runs along the circle. So the walk adds B for the whole length 2πr: B × 2πr. Ampère says that total is μ₀I, whatever the path. Hence B = μ₀I ÷ 2πr.{% endblock %} {% block try_items %}
  • Drag the marker all the way round. What does the bar reach?
  • Double r. What happens to the arrows, and what happens to the round trip?
  • Make r smaller than 1 cm, inside the wire. How much current is inside the circle now?
  • Add the return wire and make r larger than 6.25 cm. What is the round trip?
    • {% endblock %} {% block notes %}
    Note With the return wire the field is no longer the same all round the circle, so B × 2πr no longer works. The total round the circle still equals μ₀ times the current inside. The numbers here are added up piece by piece on the computer.
