{% extends "tools/base_tool.html" %} {% block stage_class %}viz-stage--tall{% endblock %} {% block lead %}A superconductor pushes a magnet's field out of itself, and the magnet floats. Find the height where the push balances the weight.{% endblock %} {% block why_text %}A superconductor is a perfect diamagnet: it makes currents on its surface that cancel the field inside completely. That behaves like a mirror magnet underneath, pointing the opposite way, so it repels the magnet above. The push falls steeply with height (as 1/h⁴), so there is one height where it equals the weight. The magnet floats there, and it is stable.{% endblock %} {% block try_items %}
  • Add mass. Does the magnet float lower or higher?
  • Double m. How does the floating height change?
  • Look at the curve above and below the crossing. If the magnet were pushed down, which way would the net force point?
    • {% endblock %} {% block notes %}
    Note A simple model: a small magnet of moment m above a flat superconductor feels the field of an image magnet of opposite sign, a distance 2h below. The force is then 3μ₀m²/(32πh⁴). Real magnets are not point dipoles, and real superconductors can also trap some field. The picture of field lines is a sketch.
