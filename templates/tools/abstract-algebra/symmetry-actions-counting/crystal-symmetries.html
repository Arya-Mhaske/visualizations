{% extends "tools/base_tool.html" %} {% block lead %}Put identical regular polygons round one corner and see which ones fit without gaps.{% endblock %} {% block why_text %}A crystal repeats one unit cell, so at any corner the angles of the shapes must add to exactly 360°. Triangles (60°), squares (90°) and hexagons (120°) divide 360° evenly. Pentagons leave a 36° gap, so a crystal cannot have 5-fold symmetry.{% endblock %} {% block notes %}
Note In 1984 Dan Shechtman found materials with 5-fold diffraction patterns. They are quasicrystals: ordered but not repeating, so they are not covered by this argument.
