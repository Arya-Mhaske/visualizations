{% extends "tools/base_tool.html" %} {% block lead %}Grow the secret primes and compare the work to use the keys with the work to break them.{% endblock %} {% block why_text %}Encrypting and decrypting take only a few dozen steps, however large n is. Breaking n means finding its factors, and the work for that grows with the size of the primes. Publishing (n, e) is safe because the only known easy road to φ(n) goes through the factors.{% endblock %} {% block notes %}
Note Trial division is the simplest attack. Real attacks are cleverer, which is why real keys use primes with hundreds of digits.
