Add them, then multiply them, and watch the bars stack.{% endblock %} {% block why_text %}In a sum the absolute errors add, so the coarsest reading sets the result: keep the fewest decimals. In a product the relative errors add, so the reading with the largest relative error (fewest sig figs) sets the result: keep the fewest sig figs.{% endblock %} {% block try_items %}
  • Add with a at 1 decimal and b at 3 decimals. Which bar decides the size of the result's bar?
  • Now multiply the same pair. Which of the two bars is now tiny, and why?
  • Give both numbers 0 decimals. Does the rule still match the error bar?
