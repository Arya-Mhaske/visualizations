Wind many turns side by side and measure them all at once.{% endblock %} {% block why_text %}The ruler is off by about one division whatever you measure. Spread that error over N turns and each turn's thickness is off by only one division ÷ N. More turns, smaller uncertainty.{% endblock %} {% block try_items %}
  • Set turns to 1. How large is the uncertainty compared with the thread itself?
  • Raise the turns to 50, then 100. Watch the uncertainty fall.
  • Change the least count to 0.5 mm. By how much does the uncertainty halve?
