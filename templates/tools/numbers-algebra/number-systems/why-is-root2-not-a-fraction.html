{% extends "tools/base_tool.html" %} {% block lead %}For each q, take the whole number p nearest to q√2. The square on p should equal two squares on q, but it never does.{% endblock %} {% block notes %}

The proof. Suppose p/q = √2 in lowest terms, so p² = 2q². Then p² is even, so p is even: p = 2k. Then 4k² = 2q², so q² = 2k² and q is even too. Both even contradicts "lowest terms". So no fraction squares to 2.
