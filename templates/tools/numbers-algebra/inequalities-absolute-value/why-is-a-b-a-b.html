If both walks go the same way, the distance you end up from zero is exactly |a| + |b|. If they go opposite ways, part of the second walk undoes the first, so you end up nearer. You can never end up farther than the total length walked. That is |a + b| ≤ |a| + |b|.{% endblock %} {% block try_items %}
