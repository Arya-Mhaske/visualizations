{% extends "tools/base_tool.html" %} {% block lead %}Drag control points and watch the curve follow.{% endblock %} {% block why_text %}A Bézier curve starts at the first control point and ends at the last. The points between pull the curve towards them without lying on it. To find the point at time t, take the fraction t of the way along each segment between control points, then repeat on the new points until one remains. Fonts, vector graphics and animation paths all use curves like this. Some formats use cubic Béziers, others quadratic.{% endblock %} {% block try_items %}
