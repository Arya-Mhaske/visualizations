{% extends "tools/base_tool.html" %} {% block lead %}Solve a small system with only a few digits of arithmetic and watch rounding error explode when the pivot is tiny.{% endblock %} {% block why_text %}A tiny pivot makes the multiplier huge, so subtracting leaves only the huge number and the small numbers vanish in rounding. Swapping rows first to use the largest available pivot keeps every multiplier at most 1 in size, so rounding errors stay small. Computers do this automatically: it is called partial pivoting.{% endblock %} {% block notes %}
Note This model rounds to a fixed number of significant figures after every operation. Real computers round in binary to about 16 digits, but the effect is the same.
