{% extends "tools/base_tool.html" %} {% block lead %}See one 2 × 2 system as two crossing lines, then as a combination of two columns reaching b.{% endblock %} {% block why_text %}In the row picture each equation is a line and the solution is the point where they cross. In the column picture the same numbers are two arrows, and the solution says how much of each arrow adds up to b. The two pictures always agree, but the column picture is the one that extends easily to many equations.{% endblock %} {% block try_items %}
  • Make the two lines parallel. What happens in the column picture?
  • Choose b so the solution is (1, 1). What do you see in each picture?
  • Find a system with no solution. Where is b in the column picture?
