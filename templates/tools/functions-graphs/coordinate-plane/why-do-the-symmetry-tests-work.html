{% extends "tools/base_tool.html" %} {% block lead %}Pick a point on a curve and mirror it. If the mirror point is on the curve for every point, the curve has that symmetry.{% endblock %} {% block why_text %}Replacing x by −x moves a point to its mirror image across the y-axis. If the new equation is the same as the old one, every mirrored point still satisfies it, so it lies on the graph. Replacing y by −y gives the x-axis. Doing both gives the origin.{% endblock %} {% block try_items %}
  • Take y = x² − 3 and mirror in the y-axis. How many of the 41 points land?
  • Take y = x³ − 3x and try all three mirrors. Which one works?
  • Take y = x² + x − 2. Does any mirror work for every point? Can a single lucky point prove symmetry?
