The rise and run swap, and one changes sign.{% endblock %} {% block why_text %}A slope triangle with run 4 and rise 2 turned through a quarter-turn has run −2 and rise 4. The slope of the new line is 4 ÷ (−2) = −2, the negative reciprocal of ½. In general, (run, rise) becomes (−rise, run), so the new slope is run ÷ (−rise), and the product of the two slopes is −1.{% endblock %} {% block try_items %}

  • Choose rise = 0. What happens to the second slope, and why?
